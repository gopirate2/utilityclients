UtilityClient 1.0.3 expands theme creation and adds community sharing.

- Sixteen preset palettes: the original five plus Ocean, Sunset, Amethyst, Nord, Cyberpunk, Cherry, Sandstone, Ice, Monochrome, Solarized and Coffee.
- Dedicated Themes editor with live draft preview, six editable colors, opacity, rounded-corner radius, panel border thickness, hover tint, name and author.
- Theme-only clipboard codes and JSON sharing, validated import previews, and an atomic local theme library. Theme imports do not change modules, friends or keybinds.
- Shared-theme documentation and a practical community Discord webhook/bot guide.
- Regression checks use isolated profile directories, so installed community modules do not interfere with or run inside the test suite.
